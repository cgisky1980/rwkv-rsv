## 2. 实现内容（`src/backend_cuda.rs`）

### 2.1 核心融合算子（decode 主干）

| 算子 | 语义 | 参考对齐 |
|---|---|---|
| `norm` | 单层 RMSNorm | Vulkan `norm.comp`（Albatross 逐位） |
| `norm_lerp6` | layer_norm + time-mix x/r/w 插值 + 6 项乘积 | Albatross `ln_mix6_cluster8_release_kernel` |
| `cmix_norm_lerp` | channel-mix norm + 插值 | Albatross `ln_cmix_centered_pack_wait_kernel` |
| `fuse_ka_dplr_norm` | k/a 时间混合 + dplr 更新 + norm 融合 | Albatross 融合 kernel |
| `gemv_f16` | fp16 权重 gemv | S3 已落地，作为 RKV stage1 基础 |
| `gemv_any4_rkv_stage1` | any4 量化 RKV stage1 gemv | any4 论文 + Albatross 融合 stage1 |
| `gemv_int8_rkv_stage1` | int8 量化 RKV stage1 gemv | int8 量化 + Albatross 融合 stage1 |
| `gemv_lowrank_chain4` | 4 段低秩投影链融合 | 低秩链融合 |
| `gemv_variant`(9 变体) | relu2 / mul_add / add × f16 / any4 / int8 | 统一 kernel，按 wtype/op 调度 |

### 2.2 采样 / token 算子（对齐 Vulkan shader，Vulkan 亦源自 Albatross）

| 算子 | 语义 |
|---|---|
| `argmax` / `argmax_into_host` | 单 block 协作求全局 argmax，平局取更小索引 |
| `sample` / `sample_into_host_seeded` / `store_sampler_host` | temperature + top-k + top-p + repetition/frequency/presence 惩罚 + splitmix 采样 |
| `record_token` / `store_token_host` | GPU self-loop 原子追加 token 到序列缓冲 |

### 2.3 关键 kernel 设计

- **NVRTC 运行时编译**：`--gpu-architecture=compute_80`，JIT 到任意 ≥ sm_80 设备；同名 kernel 缓存到
  `self.kernels: HashMap<String,(CuModule,CuFunction)>`，只编译一次。
- **gemv_rkv_stage1 / any4 / int8**：每 block 处理 4 行输出，block 内 128 线程跨 K 归约，
  `__shared__` 共享内存归约；any4 用 LUT + scale/zero，int8 直接字节反量化。
- **gemv 变体统一**：`GEMV_VARIANT_SRC` 一个 kernel 按 `wtype`（f16/any4/int8）与 `op`
  （relu2/mul_add/add）组合，减少重复代码、保证变体间性能一致。
- **动态共享内存限制**：驱动 launch 方法不支持动态 shared memory，改用静态共享内存 + 固定上限
  （`N_MAX`）+ 行边界检查。
- **采样/argmax**：单 block（256 线程）协作扫描 + 树归约，dispatch `(1,1,1)`；
  采样参数以 f32 位模式存 uint 传输，`hist` 用原子直方图统计历史 token。

## 4. 关键设计决策

- **以 Albatross faster3b 为主参考**：数学语义与 Vulkan shader（源自 Albatross）逐位对齐，
  融合 kernel 优先参考 `rwkv7_mega_ops_260602.cu`。
- **统一 gemv_variant kernel**：9 种组合（3 量化 × 3 输出算子）收敛为单一 kernel，按 `wtype`/`op` 调度，
  兼顾代码可维护性与性能一致性。
- **`CUDA_READY` 仍为 `false`**：decode 主干虽已就绪，但 gemm 等序列/矩阵算子尚未实现，
  未到整体翻转条件，`detect_backend()` 稳定回退 Vulkan。
