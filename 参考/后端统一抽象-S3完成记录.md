---

## 1. 目标

在不引入 MNN 的前提下，为 rwkv-rsv 增加 **CUDA 后端**，并实现**启动时自动选择**：
- 本机有 CUDA 硬件且算子就绪 → 用 CUDA；
- 否则回退 Vulkan。

本阶段（S3）落地**检测 + 骨架 + 自动选择**三件事，为后续逐算子补齐打地基。

---

## 2. 实现内容

### 2.1 真实 CUDA 探测 `cuda_available()`
新增 `src/backend_cuda.rs`：
- 用 `libloading` 动态加载 CUDA 驱动（Windows `nvcuda.dll` / Linux `libcuda.so.1`→`libcuda.so`）。
- 通过 CUDA **Driver API** 探测：`cuInit` 成功 + `cuDeviceGetCount ≥ 1`。
- 符号按 `_v2` 版本化名优先、旧名回退的顺序加载（`cuMemAlloc_v2`/`cuMemAlloc` 等）。

### 2.2 `CudaBackend` 骨架
- 保留首个设备的主上下文（`cuPrimaryCtxRetain`），`Drop` 时释放。
- 设备内存管理：`cuMemAlloc`/`cuMemFree` + `cuMemcpyHtoD`/`cuMemcpyDtoH`。
- 实现 `ComputeBackend` 的**张量管理**：`create_tensor` / `upload` / `upload_u32` / `download` / `download_u32` / `begin_batch` / `end_batch`。
- 全部**算子**统一返回"未实现"错误（`unimplemented(op)`），注明对齐 Albatross 后续补齐。

### 2.3 自动选择接入
- `src/backend.rs`：
  - `pub const CUDA_READY: bool = false;` —— 骨架阶段算子未就绪，暂不选 CUDA。
  - `detect_backend()`：`CUDA_READY && cuda_available()` → CUDA，否则 Vulkan。
  - `create_backend(kind)` 增加 `CudaBackend` 分支。
- `src/gpu_model.rs` `ModelBuilder::build`、`src/main.rs` 均改用 `detect_backend()` + `create_backend()`，并日志打印后端选择结果。

## 4. 关键设计决策

- **不引入 CUDA runtime/cudarc**，直接用 Driver API 动态加载，避免编译期强依赖和跨机部署问题。
- 张量以**裸 device pointer（`u64`）+ len** 存储，与 Albatross 的轻量 CUDA 后端一致，便于后续 kernel 直接以指针传参。
- 骨架阶段用 `CUDA_READY` 门控，确保 `detect_backend()` 不会选中一个跑不起来的后端（稳定回退 Vulkan）。

## 7. S3.1 补充：首个算子 `gemv_f16` 落地

在 S3 骨架基础上补上**第一个 CUDA 算子 `gemv_f16`**，验证 NVRTC 运行时编译 + kernel 启动整条链路。

### 7.1 新增内容（`src/backend_cuda.rs`）

- **NVRTC 运行时编译**：加载 `nvrtc64_120_0.dll`（Linux `libnvrtc.so.12`），
  `nvrtcCreateProgram` → `nvrtcCompileProgram`（`--gpu-architecture=compute_80`，JIT 到任意 ≥ sm_80 设备）→ `nvrtcGetPTX`。
- **Module/kernel 支持**：`cuModuleLoadDataEx` 加载 PTX、`cuModuleGetFunction` 取函数、`cuLaunchKernel` 启动。
- **kernel 缓存**：`self.kernels: HashMap<String,(CuModule,CuFunction)>`，同名 kernel 只编译一次。
- **`gemv_f16` 算子**：复核推敲后实现——
  - 要求 `M % 4 == 0`（与 kernel 每 block 4 行、对齐 Vulkan `GEMV_ROWS` 匹配）。
  - 每个 block 处理 **4 行**输出，block 内 **128 线程**跨 K 归约，`__shared__ float s[4][128]` 做共享内存归约。
  - `grid.x = M/4`，`grid.y = batch`；A 为 fp16 行主序 `(M,K)`，x/y 为 f32。
  - 参数按值传递（指针为 u64 设备地址，标量取地址）。

### 7.2 修复

- `create_tensor` 原骨架引用未定义变量 `id`（应为 `TensorId(self.next_id)`），编译期暴露并修复。
