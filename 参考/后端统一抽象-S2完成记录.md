# 后端统一抽象 — S2 实施记录

> 日期：2026-08-07
> 状态：S2 完成（GpuModel 全面迁移到 `Box<dyn ComputeBackend>`，decode + seq 全路径走 trait）

## 1. 目标

S2：把 `GpuModel` 从直接持有 Vulkan `runtime::Runtime` 迁移到持有 `Box<dyn ComputeBackend>`，
decode（单 token）与 seq（sequence-parallel）全部算子统一走 `ComputeBackend` trait。
从而让 `GpuModel` 与具体后端解耦，未来可插入 CUDA/Metal 等实现。

## 2. 改动

| 文件 | 内容 |

| `src/backend.rs` | 扩展 `ComputeBackend` trait 至 **decode+seq 全算子**（28 个算子方法）；`VulkanBackend` 实现全部算子；补充 3 处 clippy 机械修正（`&mut`→`&`） |

## 3. 关键设计决策

### 3.1 张量句柄一律传值（Copy）
trait 算子签名用 `TensorId`（`#[derive(Clone, Copy)]`），调用方不再传 `&T`/`&mut T`。
`VulkanBackend` 内部用 `get_f32/get_f16/get_u32`（返回 owned 克隆，`Tensor` 为 Arc 包装克隆仅计数递增）
与 `take_f32/put_f32`（remove/insert 规避借用冲突）做映射表访问。

### 3.2 upload/download 按 dtype 自动分派
trait 仅暴露 `upload`/`upload_u32`/`download`/`download_u32`，`VulkanBackend` 的 `upload`/`download`
按张量实际 dtype 分派到 `upload_f16`/`download_f16` 等。因此调用方无需区分 f32/f16 的上传下载，
`rt.upload_f16(&t, ...)` 一律映射为 `backend.upload(t, ...)`。

### 3.3 量化权重平台无关句柄
- `Any4Handle { idx, lut, sz, m, k }`：any4 量化三路张量 + 形状元数据。
- `Int8Handle { idx, sz, m, k }`：int8 量化二路张量 + 形状元数据。
- 调用方传 `&Handle`；`VulkanBackend` 用 `any4_ref`/`int8_ref` 组装 Runtime 所需 `GpuTensorAny4/Int8`。

### 3.4 量化类算子 Option 解包
`GpuLayer` 中量化为 `Option<Any4Handle>`/`Option<Int8Handle>`。迁移时
`gemv_any4_rkv_stage1`/`gemv_int8_rkv_stage1` 等先 `as_ref().ok_or(...)?` 解包再传 `&Handle`；
fp16 路径则 `*...as_ref().ok_or(...)?` 传值（`TensorId` 为 Copy）。

### 3.5 辅助构造器借用
`WorkBuffers::new`/`SeqBuffers::new` 内多个闭包同时捕获 `&mut dyn ComputeBackend` 会借用冲突（E0524）。
改为闭包签名接收 `b: &mut dyn ComputeBackend` 参数，调用处传 `&mut *backend`。

## 4. 迁移范围（调用点）

- `from_safetensors(mut backend: Box<dyn ComputeBackend>, path)`：`rt.create_tensor*` → `backend.create_tensor(len, TensorDtype::X)`；
  `rt.upload_f16` → `backend.upload`；`rt.drop_host(_f16/_u32)` → `backend.drop_host`。
- `ModelBuilder::build`：`VulkanBackend::new()` + `Box::new` 包装后传入。
- decode 路径 `forward_token`/`forward_layer`：`norm_lerp6`、`gemv_{int8,any4,fp16}_rkv_stage1`、
  `gemv_lowrank_chain4`、`fuse_ka_dplr_norm`、`cmix_norm_lerp`、`gemv_{int8,any4,f16}_{relu2,mul_add,add}`、
  `sample`/`argmax`、`gather_row_device_f16`、`copy_device_f16` 等。
- seq 路径 `forward_seq`/`forward_seq_layer`：`gemm`/`gemm_bias`/`gemm_add`/`gemm_relu2`/`gemm_tanh`、
  `to_f16(_triple)`、`dequant_{any4,int8}_to_f16`、`fuse_ka`、`sum_rk_rk`、`seq_shift`、`dplr_seq`、
  `elementwise_{sigmoid,sigmoid_inplace,scale_exp,mul}`、`v_first_lerp`、`gemm_any4`、`gemv_seq` 等。
- 诊断辅助 `dump_tensors`/`dump_layer_any4`/`dump_layer_int8` 也改收 `&mut dyn ComputeBackend`。
- self-loop 采样：`forward_sample_selfloop_with_state`/`forward_argmax_selfloop_with_state` 的
  `store_sampler_host`/`sample_into_host_seeded`/`record_token`/`argmax_into_host` 迁移到 trait。

  的 seed/top_k 处理或 hist 缓冲语义问题，待单独排查（不在本次抽象迁移范围）。

  `VulkanBackend::new()` 传入；CUDA 后端尚未实现（`cuda_available()` 恒 false）。
