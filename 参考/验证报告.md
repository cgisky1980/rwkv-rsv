## 关键实现要点

### 权重维度（0.1B G1）
- 低秩权重：w1[768,64], w2[64,768], a1[768,64], a2[64,768], v1[768,32], v2[32,768], g1[768,128], g2[128,768]
- FFN：key[3072,768], value[768,3072]
- r_k：[12,64] = [H,N]（非 [C]）
- x_r 等：[1,1,768] squeeze 后 [768]
- vocab=65536（非 768）

### 矩阵乘法方向
- PyTorch Linear 权重（receptance/key/value/output/ffn/head）：原 [out,in]，加载时预转置为 [in,out]
- 低秩权重（w1/w2/a1/a2/v1/v2/g1/g2）：本身 [in,out]，直接使用

### DPLR 状态更新
- A = L2_normalize(k * k_k)
- B = -A * a
- S = S * w + (S @ A) * B + V * K^T
- y = S @ r

### v_first 传播
- 每个 token 开始时重置为 None
- 第一层设置后，同 token 后续层使用

## 优化记录
